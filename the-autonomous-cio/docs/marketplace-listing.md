# Marketplace Listing

## Display Name

The Autonomous CIO

## Short Description

Executive command intelligence for enterprise leaders.

## Long Description

The Autonomous CIO turns fragmented enterprise context into board-ready briefings, cross-domain risk signals, decision memos, pre-mortems, truth-layer analysis, attention triage, risk-chain reasoning, AI governance reviews, crisis command views, transformation playbooks and action plans.

It is a connector-neutral skill-first plugin for CIO, CISO, COO, CFO, risk, compliance and enterprise architecture work. Users provide meeting notes, project lists, risk registers, budget updates, architecture context, security findings, audit notes, process descriptions or other enterprise context. The plugin turns that input into structured executive artifacts while clearly separating facts, assumptions, hypotheses and missing data.

## Core Use Cases

- Build board-ready CIO/CISO briefings.
- Triage enterprise signals into monitor, decide, escalate and act-now categories.
- Detect strategy drift, decision debt and value leakage.
- Map cascading risks across projects, architecture, security, compliance, finance and operations.
- Prepare crisis command views and executive action plans.
- Review AI use cases for value, data risk, controls and approval readiness.
- Challenge proposals before board or steering approval.
- Convert meetings into decisions, risks, actions and executive memory.

## Key Capabilities

- 44 connector-neutral Codex skills.
- Orchestrator skill for broad executive requests.
- Executive playbooks for board prep, crisis command, AI approval, transformation control and monthly CIO reviews.
- Templates for board packs, operating reviews, decision memos and risk-to-action registers.
- Evidence-aware output model that separates facts, inferences, hypotheses, assumptions and missing data.

## Boundaries

- No live system access in version 0.1.
- No automatic persistence.
- No external actions without future connector tools and explicit user approval.
- Legal, regulatory, HR, security and financial outputs are decision support, not final specialist determinations.

## Suggested Starter Prompts

- Create a board-ready CIO briefing from this context.
- Triage risks, decisions and executive actions.
- Build a command-center situation report.
