# Neutral Promotion Kit

This kit provides neutral, review-safe promotion material for The Autonomous CIO. It avoids customer-specific claims, live-system claims, replacement claims and unsupported autonomy claims.

## Positioning Guardrails

Use:

- Local Codex plugin
- AI-native executive decision intelligence
- Decision-support operating system
- User-provided context and local exports
- Board-ready decision packets
- Evidence gaps, risk chains, challenge questions and draft next actions
- Connector-neutral, local-first, human-approved

Avoid:

- Replaces a CIO
- Executes enterprise actions
- Has live access to Outlook, Teams, ERP, ITSM or ticketing systems by default
- Provides legal, financial, security or regulatory final decisions
- Learns secretly, trains on customer data or self-modifies
- Guarantees risk reduction, audit approval or business outcomes

## Master Description

The Autonomous CIO is a local Codex plugin for AI-native executive decision intelligence. It turns fragmented enterprise context into board-ready decision packets, CIO Autopilot Reviews, risk chains, evidence gaps, board challenge questions, action drafts and governed memory proposals.

It is built for CIOs, CISOs, COOs, CFO-facing technology leaders, enterprise architects, PMO teams, risk teams and executive operations teams that need to convert enterprise noise into governed decisions. Version 0.1 is connector-neutral and local-first: it works with user-provided context, local files and exports, and does not claim live system access or external action execution.
