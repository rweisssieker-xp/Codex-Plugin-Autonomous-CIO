# Skill Suites

The Autonomous CIO has many specialist skills, but users should experience them as a small set of coherent suites. Route through these suites first; use specialist skills as modules inside the suite.

## 1. Executive Operating System

Primary skill: `autonomous-cio-operating-review`

Use for broad CIO reviews, monthly operating reviews, Board in 48h preparation, mixed enterprise context and "run the CIO" requests.

Includes: `enterprise-command-center`, `enterprise-briefing`, `enterprise-control-tower`, `operating-rhythm-autopilot`, `cio-os-maturity-index`, `cio-work-autonomy-map`, `human-control-contract`, `autonomous-action-framework`, `autonomous-executive-memory`.

## 2. Executive Decision Intelligence

Primary skill: `executive-decision-packet`

Use for approvals, trade-offs, board decisions, portfolio decisions, risk acceptance and executive commitments.

Includes: `executive-truth-layer`, `enterprise-signal-ranking`, `risk-chain-intelligence`, `decision-scenario-intelligence`, `board-challenger`, `executive-q-and-a-simulator`, `decision-consequence-mapper`, `decision-debt-intelligence`, `decision-debt-ledger`, `decision-sla-enforcer`, `decision-rights-mapper`, `risk-acceptance-docket`, `executive-decision-war-room`.

## 3. Board And Narrative Defense

Primary skill: `board-challenger`

Use before Board, CEO/CFO/CISO/Audit or steering approval when the narrative must survive pressure.

Includes: `board-objection-simulator`, `board-decision-simulator`, `executive-narrative-generator`, `stakeholder-alignment-matrix`, `truth-gap-detector`, `narrative-consistency-scanner`, `autonomous-due-diligence-questions`, `executive-reporting`.

## 4. Risk, Resilience And Controls

Primary skill: `risk-chain-intelligence`

Use for cascading risk, crisis, audit, compliance, security, resilience and operational exposure.

Includes: `crisis-command-mode`, `risk-compliance-intelligence`, `governance-gap-predictor`, `regulatory-horizon-scanner`, `regulatory-shock-simulator`, `compliance-evidence-pack`, `audit-finding-predictor`, `security-business-translator`, `cyber-business-impact-translator`, `zero-trust-executive-intelligence`, `resilience-continuity-planner`, `service-health-sentinel`, `operating-risk-heatmap`.

## 5. Transformation, Portfolio And Value

Primary skill: `transformation-value-tracker`

Use for value leakage, portfolio trade-offs, roadmap decisions, spend, benefits, project risk and transformation drift.

Includes: `project-portfolio-intelligence`, `portfolio-cannibalization-detector`, `value-leakage-intelligence`, `benefits-realization-sentinel`, `finance-investment-intelligence`, `capital-allocation-copilot`, `cost-of-delay-calculator`, `strategy-drift-intelligence`, `strategic-drift-detector`, `strategic-option-portfolio`, `transformation-readiness-intelligence`, `transformation-kill-criteria`, `autonomous-roadmap-reprioritizer`.

## 6. Industrial IT/OT, Quality And Manufacturing

Primary skill: `industrial-cio-operating-system`

Use for regulated manufacturing, production-continuity risk, IT/OT interfaces, ERP/MES/QMS/PLM dependencies, audit evidence, change-control readiness, vendor exposure and customer-channel impact.

Includes: `it-ot-production-risk-command`, `qms-audit-evidence-readiness`, `risk-chain-intelligence`, `architecture-data-security-intelligence`, `vendor-ecosystem-intelligence`, `resilience-continuity-planner`, `compliance-evidence-pack`, `service-health-sentinel`, `customer-trust-impact-radar`, `decision-rights-mapper`, `autonomous-action-framework`.

## 7. Architecture, Data, AI And Vendor

Primary skill: `architecture-data-security-intelligence`

Use for architecture readiness, technical debt, AI governance, data trust, vendor risk and platform decisions.

Includes: `technical-debt-capitalizer`, `architecture-runway-guardian`, `data-trust-radar`, `data-product-governance-intelligence`, `data-sovereignty-radar`, `ai-governance-intelligence`, `ai-portfolio-governance`, `policy-as-code-readiness`, `vendor-ecosystem-intelligence`, `vendor-exit-simulator`, `vendor-negotiation-brief`, `platform-rationalization-advisor`.

## 8. Organization, Operating Model And Knowledge

Primary skill: `organization-workforce-intelligence`

Use for ownership, capacity, talent, operating model debt, friction and knowledge continuity.

Includes: `enterprise-friction-intelligence`, `operating-model-simulator`, `operating-model-debt-ledger`, `process-operations-intelligence`, `talent-criticality-radar`, `knowledge-continuity-planner`, `dependency-breakpoint-analyzer`, `exception-waiver-factory`, `customer-trust-impact-radar`, `ma-carveout-readiness`.

## Routing Rule

Use a suite primary skill unless the user explicitly asks for a specialist artifact. Specialist skills should usually appear as modules inside one of the eight suites, not as the first visible choice.
