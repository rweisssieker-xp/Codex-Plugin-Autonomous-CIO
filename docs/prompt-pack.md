# Prompt Pack

Copy these prompts into Codex and replace bracketed context with real enterprise information.

## Autonomous CIO Orchestrator

```text
Use autonomous-cio-orchestrator. I do not know which skill to use. Build the right executive workflow for this situation:
[paste mixed enterprise context]
Return selected skill chain, executive summary, decisions, risks, actions and missing data.
```
