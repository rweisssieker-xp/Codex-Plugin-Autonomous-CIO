# AI Feature Map

This map groups The Autonomous CIO's AI features into reusable executive capabilities.

## Signature AI Mechanisms

- CIO autopilot review: combines decision packet, risk chain, evidence graph, action ledger, memory update and operating rhythm.
- Evidence classification: separates facts, inferences, assumptions, hypotheses, narratives and missing evidence.
- Weak signal ranking: elevates signals by executive relevance, impact, urgency, novelty, dependency reach and uncertainty.
- Contradiction detection: compares reports, roadmaps, budgets, status updates and decision logs for narrative mismatch.
- Risk propagation: maps cascading exposure across projects, architecture, security, compliance, finance, vendors and operations.
- Decision debt mining: finds unresolved, delayed, implicit or poorly owned decisions.
- Board pressure simulation: generates likely CEO, CFO, CISO, Audit, regulator, customer and Board questions.
- Value leakage detection: identifies spend, capacity, vendor activity or transformation work without enough measurable value.
- Decision readiness scoring: evaluates whether approval quality is strong enough for steering or Board decision.
- Evidence graphing: connects claims, facts, assumptions, missing evidence and contradictions.
- Executive memory comparison: checks new updates against prior decisions, assumptions and open actions.
- Autonomy readiness scoring: evaluates whether action drafting can remain governed, reversible and human-approved.
- Visual decision intelligence: renders scores, evidence heatmaps, risk chains and decision debt into a local command-center view.
- Semantic extraction: identifies enterprise entities, claims, dependencies and open decisions.
- Scenario simulation: compares approve now, defer and approve with conditions.
- Audit trail generation: records score drivers, recommendation drivers and source scope.
- Connector-ready signal contracts: normalize future meeting, document, delivery, incident and finance signals.
- Connector profile catalog: defines safe signal contracts for Outlook, Teams, SharePoint, GitHub, TOPdesk and industrial file drops without live access.
- Connector export adapter: converts local CSV/JSON/TXT/Markdown exports into normalized decision signals.
- Connector profile detection: infers the likely export profile from local fields and values.
- Skill orchestration runtime: detects request type and domains, selects a skill chain and returns an integrated decision-support bundle.
- LLM extraction contract: standardizes fact, assumption, weak-signal, contradiction and missing-evidence extraction for Codex-host reasoning.
- Explicit memory inspection: reviews local memory stores for stale assumptions, open decisions and draft actions.
- Decision export package: writes local board, audit, steering, action-ledger and decision-log artifacts from one decision context.
- Office export package: generates local `.docx` and `.pptx` decision artifacts without cloud services.
- Executive Decision Assurance: combines Codex-LLM semantic extraction, entity resolution, causal graphs, counterfactuals, decision twins, board coverage, narrative-risk detection, anti-pattern detection, red/blue-team challenge, attention budgeting, latency, value-at-risk, governance controls, meeting-to-decision diff and packet quality grading.
- Executive Decision Defense: protects decisions with liability shielding, blind-spot detection, commitment integrity, board narrative stress testing, value firewalling, risk-to-cash translation, SLA monitoring, control evidence readiness, attention allocation and kill-switch criteria.

## Decision Intelligence Loop

```text
Signals -> Truth -> Risk Chain -> Options -> Actions -> Memory
```

The loop is the visible product mechanism behind `executive-decision-packet`. It converts provided enterprise context into a decision-ready artifact with decision needed, facts vs assumptions, risk chain, options, board challenge questions, recommended action, missing evidence and draft next steps.

## Executive Decision Assurance

The local engine command `python engine/cli.py assurance --input engine/examples/board_prep.json` proves 15 advanced AI capabilities in one reviewable output:

- Codex host LLM extraction layer with heuristic fallback for standalone engine runs.
- Entity resolution across ERP, vendors, IAM, audit, cloud and other enterprise signals.
- Causal decision graph that links causes, mechanisms, intermediate effects and outcomes.
- Counterfactual simulation for capacity, deferral and vendor recovery interventions.
- Decision twin that keeps the current decision, assumptions, options and consequences together.
- Board question coverage score across CEO, CFO, CISO, Audit, regulator and customer personas.
- Narrative risk detector for optimistic, political or unsupported status language.
- Decision anti-pattern library for approval without evidence, date-driven delivery, unfunded dependencies, ownerless risk and control-gap normalization.
- Red Team / Blue Team mode for hard challenge and defensible mitigations.
- Executive attention budget that separates top items, delegated evidence work and monitored signals.
- Decision latency tracker for stale or drifting decisions.
- Value-at-risk estimate as a directional, non-financial-advice exposure band.
- Governance control map for CISO, Audit, CFO and architecture controls.
- Meeting-to-decision diff when meeting notes and decisions are both supplied.
- Decision Packet Quality Grade for board, audit and action readiness.
