# Post Decision Learning Loop

## Mission

Make every major decision improve the next one by capturing what was assumed, what happened and what should change in executive memory.

## Inputs

Accept decision logs, prior decision packets, action ledgers, review notes, incident retrospectives, benefits tracking and memory exports.

## Workflow

1. Identify decision, assumptions, expected outcomes and safeguards.
2. Compare later evidence against assumptions.
3. Capture lessons, missed objections, risk changes and owner follow-through.
4. Update memory targets: decision twin, assumption register, risk chain and action ledger.
5. Recommend next review cadence.

## Output Format

- Executive Summary
- Decision Reviewed
- Assumption Outcomes
- Risk / Value Changes
- Learning Items
- Memory Updates
- Next Review Cadence

## Guardrails

Do not rewrite history. Separate hindsight, evidence and interpretation.
